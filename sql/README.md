# SQL Files – Online Reservation System

This folder contains the database scripts used for the Online Reservation System.

## Files Included
• reservation_tables.sql – Creates all required tables such as users, trains, reservations and cancellations.

## How to Use
1. Open your MySQL or any compatible SQL client.  
2. Create a new database (example):  
   CREATE DATABASE reservation_system;
3. Select the database:  
   USE reservation_system;
4. Run the script from this folder to create all required tables.

These tables are used by the Spring Boot backend for storing user details, train data and reservation information.
