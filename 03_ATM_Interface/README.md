# 🏧 ATM Interface

This project is part of **Task 03** of the **OASIS INFOBYTE Java Developer Internship**.

The ATM Interface is a Java console based application that simulates basic ATM operations after user authentication.

---

## 📌 Features
- User ID and PIN validation  
- Withdraw money  
- Deposit money  
- Transfer funds  
- Transaction history  
- Exit option  

---

## 🛠 Tech Stack
- Java  
- Core Java concepts  
- OOP principles  
- Console based interaction  

---

## ⚙️ How It Works
1. User enters User ID and PIN  
2. On successful login, ATM menu is displayed  
3. User selects operations like withdraw, deposit, transfer  
4. Transaction history is stored and displayed  
5. User can exit the system anytime
