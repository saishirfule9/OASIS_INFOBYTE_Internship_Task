# 01_Online_Reservation_System

React frontend and Java Spring Boot backend demo for an online reservation system.
Includes a simple reservation form and a backend REST API that stores reservations in memory.

Folders:
- frontend : React app (Vite)
- backend  : Spring Boot app (REST API)
- sql      : DB schema (sample)
- docs     : run instructions and screenshots
