# Digital Library Management System

This project is part of **Task 05** of the **OASIS INFOBYTE Java Developer Internship**.

The Digital Library Management System is a Java console based application that manages basic library operations such as viewing books, adding new books, and issuing books.

---

## 📌 Features
- View available books
- Add new books
- Issue books
- Menu driven console interface
- Exit option

---

## 🛠 Tech Stack
- Java
- Core Java concepts
- Java Collections
- Console based interaction

---

## ⚙️ How It Works
1. System displays a menu of operations  
2. User selects an operation  
3. Books can be viewed, added, or issued  
4. Library data is updated dynamically  
5. User can exit the application anytime  

---

## ▶️ How to Run
1. Open terminal or command prompt  
2. Navigate to the `src` folder  
3. Compile the Java file:

4. Run the program:javac DigitalLibrary.java
