# Backend – Online Reservation System

This folder contains the Java Spring Boot backend for the Online Reservation System.  
The backend handles user login, train data, reservation submission, cancellation and database interaction.

## Features
• User authentication  
• Reservation API  
• Cancellation API  
• Train and ticket details  
• MySQL database integration  

## Tech Stack
• Java  
• Spring Boot  
• REST APIs  
• MySQL  
• Maven  

## How to Run
1. Open this folder in your IDE (STS or IntelliJ)  
2. Make sure MySQL is running  
3. Update database username and password in application.properties  
4. Run the Spring Boot application  
5. Backend will start at:  
   http://localhost:8080

The backend serves APIs consumed by the React frontend.
