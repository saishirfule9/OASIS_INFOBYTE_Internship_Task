# Online Examination System

This project is a Java console based Online Examination System developed as part of the OASIS INFOBYTE Java Developer Internship.

The application allows users to log in, attempt an online examination with multiple choice questions, and view their final score.

## Features
- User login
- Multiple choice questions
- Automatic score calculation
- Result display after exam completion

## Technologies Used
- Core Java
- Java Collections
- Console based application

## How to Run
1. Open the project in any Java supported IDE
2. Compile and run OnlineExamination.java
3. Login and start the examination
