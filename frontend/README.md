# Frontend – Online Reservation System

This folder contains the React based frontend for the Online Reservation System.  
The interface allows users to log in, search trains, make reservations and cancel bookings.

## Features
• User login  
• Reservation form  
• Train selection  
• Ticket details display  
• Simple and clean UI  

## Tech Stack
• React  
• Vite  
• JavaScript  
• Bootstrap  

## How to Run
1. Open a terminal inside this folder  
2. Install dependencies  
   npm install  
3. Start the frontend server  
   npm run dev  
4. Open the URL shown in the terminal

The frontend communicates with the backend API created in Spring Boot.
